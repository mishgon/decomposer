# SFT build specifications

Each file here is a `spec_version: 4` build specification; see `sft/README.md`
for the pipeline. New specifications name the dataset `decomposer-manager-sft`
and set `dataset.version` to the release's semantic version (see *Snapshots,
releases and versioning* in `sft/README.md`).

The specification of published release 1.0.0 (fingerprint `fb6d86f6…`),
`decomposer_manager_sft_1.0.0.yaml`, lives at commit `53a88d8`, the only commit
that reproduces the release. Every other earlier specification and every
training config were removed on 2026-10-13; see *Legacy specs and configs* in
`sft/README.md`.
